description: 基于高可信度的一手资料调查问题，并将结论记录为仓库内的 Markdown 文件。当用户希望研究某个主题、收集文档或 API 事实，或将阅读工作委派给后台代理时使用。
---

启动一个**后台代理**开展研究，这样你可以在它阅读资料时继续工作。

它的任务：

1. 基于**一手资料**调查问题，例如官方文档、源代码、规范和第一方 API，而不是依赖二手文章。将每项主张追溯到对其负责的原始来源。
2. 将结论写入一个 Markdown 文件，并为每项主张标注来源。
3. 将文件保存到仓库现有的同类笔记位置；遵循已有约定，如果没有约定，则放到合理位置并说明路径。
