# Triage Labels

这些 skill 使用五个规范 triage role。本文件将这些 role 映射到此仓库 issue tracker 中实际使用的 label 字符串。

| mattpocock/skills 中的 Label | 我们 tracker 中的 Label | 含义 |
| ---------------------------- | ----------------------- | ---- |
| `needs-triage`               | `needs-triage`          | 维护者需要评估此 issue |
| `needs-info`                 | `needs-info`            | 等待报告者提供更多信息 |
| `ready-for-agent`            | `ready-for-agent`       | 已完整说明，可以交给 AFK agent |
| `ready-for-human`            | `ready-for-human`       | 需要人类实现 |
| `wontfix`                    | `wontfix`               | 不会处理 |

当 skill 提到某个 role 时（例如“应用 AFK-ready triage label”），使用此表中对应的 label 字符串。

编辑右侧列，使其与你实际使用的词汇一致。
