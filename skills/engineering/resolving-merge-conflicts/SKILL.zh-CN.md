---
name: resolving-merge-conflicts
description: "当需要解决正在进行的 git merge/rebase 冲突时使用。"
---

1. **查看 merge/rebase 的当前状态。**检查 git 历史和发生冲突的文件。

2. **查找每个冲突的一手资料。**深入理解每项改动为何产生，以及它最初的意图。阅读 commit message、检查 PR，并查看原始 issue/task。

3. **逐个解决冲突块。**尽可能保留双方意图。如果两者不兼容，选择符合本次合并既定目标的一方，并说明取舍。**不要**创造新行为。始终解决冲突，绝不使用 `--abort`。

4. 找出项目的**自动化检查**并运行，通常依次是类型检查、测试和格式化。修复合并破坏的所有内容。

5. **完成 merge/rebase。**暂存所有内容并提交。如果正在 rebase，继续该过程，直到所有提交都完成 rebase。
