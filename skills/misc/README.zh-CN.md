# 杂项

我保留但很少使用的工具，不会在插件中推广。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.zh-CN.md)** — 设置 Claude Code hook，在危险的 git 命令（push、reset --hard、clean 等）执行前将其阻止。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.zh-CN.md)** — 将测试文件从 `as` 类型断言迁移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.zh-CN.md)** — 创建包含章节、题目、答案和讲解的练习目录结构。
- **[setup-pre-commit](./setup-pre-commit/SKILL.zh-CN.md)** — 设置 Husky pre-commit hook，并配置 lint-staged、Prettier、类型检查和测试。
