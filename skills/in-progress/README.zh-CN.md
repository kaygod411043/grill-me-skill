# 开发中

这些技能仍在开发，尚未准备好发布；可能存在粗糙之处、破坏性变更和被放弃的实验。在晋升到稳定 bucket 之前，它们不会进入插件和顶层 README。

- **[loop-me](./loop-me/SKILL.zh-CN.md)**：在多次会话中，通过深入追问把自己的循环整理成可实现的工作流规格说明，并将当前目录作为有状态工作区。仅由用户调用。
- **[wizard](./wizard/SKILL.zh-CN.md)**：生成交互式 bash 向导，引导用户完成手工流程（配置、一次性迁移、状态转换），包括打开 URL、采集值、写入 `.env` 和 GitHub Actions secret。仅由用户调用。
- **[writing-beats](./writing-beats/SKILL.zh-CN.md)**：以“选择你自己的冒险”方式，把文章塑造成由节拍组成的旅程；选择起始节拍，只写这一个，再转向下一个，直到自然结束。
- **[writing-fragments](./writing-fragments/SKILL.zh-CN.md)**：通过深入追问挖掘异质的写作片段，并将其追加到同一文档，作为未来文章的原始材料。
- **[writing-shape](./writing-shape/SKILL.zh-CN.md)**：读取一个包含原始材料的 Markdown 文件，逐段塑造成文章，并在每一步讨论格式选择。
- **[claude-handoff](./claude-handoff/SKILL.zh-CN.md)**：通过 `claude --bg` 传入交接摘要，将当前对话立即交给新的后台代理继续处理。仅由用户调用。
- **[setup-ts-deep-modules](./setup-ts-deep-modules/SKILL.zh-CN.md)**：将 dependency-cruiser 接入 TypeScript 仓库，使每个包都成为深模块：实现隐藏于子目录，只能通过入口点文件访问，测试也通过入口点执行。仅由用户调用。
- **[to-questionnaire](./to-questionnaire/SKILL.zh-CN.md)**：把无法独自回答的决策转化为 Markdown 问卷，交给他人异步填写或在会议中共同完成；它追问发送方式（交给谁、需要什么），而不是问题主题。仅由用户调用。
- **[batch-grill-me](./batch-grill-me/SKILL.zh-CN.md)**：按轮次遍历设计树的深度访谈；每一轮提出所有前置决策已经确定的前沿问题，再根据答案重新计算前沿。仅由用户调用。
