---
name: handoff
description: 将当前对话压缩为交接文档，供另一个代理继续处理。
argument-hint: "下一次会话将用于什么？"
disable-model-invocation: true
---

编写一份当前对话的交接文档，让新的代理能够继续工作。将它保存到用户操作系统的临时目录，而非当前工作区。

在文档中加入“建议技能”章节，推荐代理应调用的技能。

不要重复其他工件（规格说明、计划、ADR、Issue、提交、diff）中已经记录的内容，改为引用其路径或 URL。

移除 API 密钥、密码、个人身份信息等任何敏感信息。

如果用户传入了参数，将其视为下一次会话的工作重点描述，并据此调整文档。
